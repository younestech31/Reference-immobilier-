# المرجع العقاري الجزائري | Algerian Real Estate Reference

مستودع بيانات مستقل وتطبيق Android أصلي لعرض نطاقات الأسعار المرجعية العقارية في الجزائر.

## قاعدة البيانات المستوردة

تم نسخ ملفات المصدر الأصلية من:
- المستودع: https://github.com/younestech31/Lattab
- الفرع: `main`
- commit المصدر: `fc2e85f0cb4d20fd3eb2961a95a5aed42cca3309`

المجلد `data/source/` يحتوي على:
- 116 ملف أسعار أصلية: 58 ولاية × نوعي البيانات (بيع وإيجار).
- `wilayas.ts`: قائمة الولايات وأسماؤها ورموزها.
- `price-reference.ts`: تعريف بنية البيانات الأصلية.

أنواع البيانات:
- `*-price-reference-transactions.ts`: مرجع عمليات البيع.
- `*-price-reference-locations.ts`: مرجع الإيجار.

**تم الحفاظ على الأرقام والحدود الدنيا والعليا والتسميات والوحدات والفئات وأسماء المناطق كما وردت في المصدر، دون إعادة حساب أو تعديل.**

## ملاحظة مهمة

هذه نطاقات مرجعية إدارية وليست تقييماً سوقياً ملزماً أو سعراً مضموناً للبيع أو الإيجار، وليست أتعاب موثق.

## تطبيق Android

سيُبنى التطبيق كتطبيق Android أصلي باستخدام Kotlin وJetpack Compose، مع قاعدة بيانات محلية للعمل دون إنترنت. ستُنشأ لاحقاً ملفات JSON مهيأة للتطبيق من ملفات المصدر مع اختبارات تحقق ومطابقة، مع الاحتفاظ بملفات المصدر لأغراض التتبع والتدقيق.

## مزامنة المصدر

يحتوي `.github/workflows/sync-reference-data.yml` على إجراء لاستيراد أحدث ملفات المرجع من فرع `main` في Lattab إلى فرع العمل عند تشغيله.
